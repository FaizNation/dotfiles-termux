# My Termux Dotfiles

Ini adalah koleksi file konfigurasi pribadi (dotfiles) saya untuk Termux.

Repositori ini membantu saya dengan cepat mengatur lingkungan Termux baru persis seperti yang saya suka. Ini mencakup konfigurasi Zsh (`.zshrc`) dan pengaturan styling Termux (`.termux/`).

## Instalasi Cepat

Untuk mengembalikan konfigurasi ini di instalasi Termux baru, ikuti langkah-langkah berikut:

```bash
# 1. Instal Git
pkg install git

# 2. Clone repositori ini
git clone https://github.com/FaizNation/dotfiles-termux.git

# 3. Jalankan skrip instalasi
~/dotfiles/install.sh

# 4. Selesai!
# Tutup dan buka kembali Termux Anda untuk melihat perubahannya.
